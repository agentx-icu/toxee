# toxee 与 tim2tox 全功能代码审核计划

目标是追踪已交付功能的正常入口、状态恢复和跨层契约，复现并修复确认的缺陷，独立复审改动并在 CI 通过后合并。

审核基线为 toxee `089de217` 与其锁定的 tim2tox `98c5b25`。tim2tox 默认分支 `4a1dafa` 用于核对上游差异。依赖基线以 `.gitmodules`、gitlink 和 SDK 锁文件为准。

## 功能覆盖

| 负责方 | 审核范围 | 主要入口与验证 |
| --- | --- | --- |
| Agent 1 | 启动、注册、登录和自动登录、多账户、密码与数据迁移、备份和导入导出、会话切换、设置、偏好、安全存储、日志和隐私 | `lib/{auth,bootstrap,runtime,startup,util}`、登录和设置页面、`test/{auth,bootstrap,account_export,runtime,util}`、账号与会话文档 |
| Agent 2 | 联系人及个人资料、单聊和自聊、群聊、会话列表、历史与未读、同步和离线队列、回执、媒体和文件、搜索与转发 | `lib/{ui,sdk_fake,adapters}`、UIKit fork 的应用入口、`tim2tox/dart/lib/{sdk,service,models,utils}` 和消息、文件、群及历史测试 |
| Agent 3 | tim2tox 原生 Tox 生命周期、Bootstrap、传输、V2TIM 管理器、群与会话、文件、信令及 ToxAV、回调、C FFI、Dart 绑定和二进制替换 | `tim2tox/{source,include,ffi,dart/lib/ffi,test,auto_tests}`，检查符号、签名、JSON、实例和内存所有权 |
| 主审 | 通话端到端、附近的人与定位、配对、通知、平台生命周期与权限、主题/语言/导航、各平台 runner、构建和依赖、CI 与跨层交叉检查 | `lib/{call,nearby,notifications,navigation}`、平台目录、`tool`、`.github/workflows`、集成和设备测试入口 |

各负责人以 README、架构和 Reference 文档及测试场景清单核对功能入口，记录覆盖、证据和设备验证缺口。重点检查正常入口、失败与取消、重复调用、异步回调、进程重启、旧数据和不同平台。每条发现记录严重度、文件与行、受影响入口、预期行为、根因和最小回归检查。原生网络输入仅做防御性代码检查和正常功能测试。

## 执行与合并

1. 隔离 checkout 并锁定子模块。以 Flutter 3.41.9 建立静态分析、复杂度、Flutter 测试和原生验证基线。
2. 并行只读审核。主审逐条确认、合并重复项，优先处理数据丢失、崩溃和核心流程失败。按根因修复，给现有测试未覆盖的缺陷增加回归检查，保留测试结果。
3. 核对共享代码的五平台覆盖和平台专属行为，按移动设备特性清单记录验证结果。适用时运行 ABI 检查、原生单测、tim2tox 虚拟场景和 E2E。
4. 复用上述 agent 独立复审最终 diff，核对设计约束、用户可见行为、向后兼容和测试质量。修复新增问题，重跑受影响门禁并复审。
5. 如需更新 tim2tox，先开其 PR，在对应提交的 CI 通过后合并，再在 toxee 更新 gitlink。toxee PR 写明审核覆盖、修复及验证，等当前提交的 CI 通过后合并并核验合并提交。

## 第二轮深审

在第一轮修复基础上再开六名独立审核者，按工具并发上限分批运行。初审与复审均沿生产入口追踪，优先用可控失败、进程重启、并发操作和跨账号切换验证状态归属。

| 深审负责人 | 审核重点 |
| --- | --- |
| 账号与数据 | 注册、删除、切换和导入导出在中断或磁盘拒绝后的恢复，旧版本数据和凭据归属 |
| 原生与 FFI | Tox 实例和轮询生命周期、事件和缓冲区归属、并发传输、群与网络重连、SDK 二进制与平台路径契约 |
| 消息与持久化 | 冷热历史交界、归档与清除、消息身份和回执、离线队列和重试、联系人和群会话的端到端状态 |
| 通话与媒体 | 拨打及接听、原生互操作、通话记录、共享音频与视频、权限撤回、切换设备和前后台时序 |
| 通知与设备 | 冷启动通知归属、锁屏与后台、当前位置和附近的人、配对、交互与无障碍、原生桥接 |
| 构建与交付 | 干净引导、锁定依赖、可重复构建、各平台安装与权限声明、CI 覆盖与回归门禁 |

在此轮确认的问题修复并完成独立复审后提交 toxee PR。若 tim2tox 需要第二个 PR，则以该 PR 的通过版本更新 toxee 的 gitlink 和日志 overlay。
