# 外观与布局实施记录

2026-10-01。经典蓝保持默认，新增清爽现代、夜航通讯、纸感书信、清新卡通；每种风格支持浅色、深色和跟随系统。

## 使用与行为

在设置的「外观」中选择风格和明暗，先查看本地聊天预览，再点击「应用」。重置只暂存经典蓝／跟随系统，需要应用才生效。退出设置丢弃未应用选择；保存失败保留当前全局外观和待应用选择，可重试。

风格和明暗以版本 1 JSON 一起写入设备级 `appearance_settings`，成功保存后发布。旧 `theme_mode` 兼容读取，未知或损坏数据回退到经典蓝和有效旧明暗。账号切换不会改变设备外观。

Material 与聊天 UIKit 共用语义颜色、圆角和描边。卡通采用暖杏／珊瑚／淡紫、2px 深色轮廓、气泡尾角及选中导航偏移阴影；纸感采用方正的小圆角。消息时间戳使用完整次要文字色，减少旧透明度造成的对比度损失。

中等宽度 720–1099px 使用 72px 紧凑导航，底部导航仍在 720px 以下，主从布局仍从 800px 起启用。会话列表在 280–330px 间适应空间，尽可能给聊天区留 360px。输入框从两行增长到配置上限，保留原控制器与 IME。桌面外观提前、常规设置分组；移动与账号复制按钮至少 44px。登录恢复／导入增加用途说明。

好友申请的列表、菜单、详情统一处理成功、失败、异常；仅成功删除，失败可重试，按钮可换行且完整点击。申请中的 SDK 会话、当前账号、申请人共同隔离重复操作；旧账号操作结束后不会更新新账号的数据或通知。
