# 位置消息与"附近的人"

toxee 可以把你的当前位置发给好友或群，也可以显示同一区域内的其他 toxee
用户，方便你向他们发送好友请求。两者都不使用服务器：位置消息走加密的好友链路，
"附近的人"通过 Tox DHT 与陌生人会合。两者**默认都关闭**。

## 开关（设置）

| 开关 | 默认 | 控制什么 |
|---|---|---|
| **位置** | 关 | 一切会读取本设备位置的功能：输入框里的"位置"选项和"附近的人"。关闭时 toxee 绝不向系统请求位置。开启时会申请系统定位权限（仅使用期间）；拒绝则开关保持关闭，并说明如何在系统设置里允许。 |
| **对附近的人可见** | 关（需先开启"位置"） | 加入你所在区域的会合单元并广播在场记录。首次开启会显示隐私说明。 |

两者都按账号保存。切换账号时会自行停止；App 退到后台、附近页关闭五分钟、
或任一开关被关闭时，"附近的人"都会停止。

## 位置消息

*输入框 → 位置*（桌面工具栏、移动端附件面板）。toxee 读取一次位置并作为位置
消息发送；接收方看到带坐标的气泡、"在地图中打开"（调用系统地图应用；toxee
不联系任何地图服务商）和"复制"。单聊与群聊、全部平台可用。位置精度与系统
给出的一致——是否发送由你决定，和任何消息一样。

## 附近的人

入口：*添加联系人 → 附近的人*，或设置里开关下方的按钮。

你能看到：约 5 公里内同样开启了"对附近的人可见"的人，显示昵称和大致距离。
对方能看到你的：昵称、头像哈希和取整到约 100 米的位置，页面打开期间大约每
分钟刷新一次。应用进入后台时"附近的人"会暂停，回到页面（或点击刷新）后重新
开始；当前区域的单元暂时无法加入时页面会说明，并在后台持续重试。

*打招呼*会向对方发送请求，可附一句话（最多 140 个字符；计数器显示一个数据包
能装下的字节数，非拉丁文字约 200 字节）。**这是你的 Tox ID 唯一离开设备的时刻**：
经确认后，它被加密发送给那一个人。对方接受时会向你发送一条普通的 Tox 好友
请求，以"附近的人回复了你"卡片的形式出现，带对方公钥，一键添加。对方拒绝
则什么都不会发生。

有人向你打招呼时，你会收到带对方昵称和留言的卡片。*接受*会向对方发送好友
请求（对方的 Tox ID 就在请求里）；*拒绝*则丢弃。*屏蔽*在本次会话内隐藏此人。

### 需要知道的限制

这些都是没有服务器的必然结果，不是缺陷：

- **任何人都能看。** 单元是公开群，群 ID 人人可算，所以你所在区域的任何人都
  能看到和你一样的列表。因此只广播粗化位置和每次会话的临时密钥，且绝不广播
  Tox ID。
- **位置是自报的。** toxee 无法核实对方真的在哪里，也无法核实昵称和头像。
- **没有全局管理。** 没有举报，也没有全局封禁；屏蔽只在本地。请求有频率限制
  （每小时最多发 5 个、每人每小时最多收 3 个）。
- **分享 Tox ID 即是披露。** 你联系过的人可能把你的 Tox ID 转给别人。如果
  成为困扰，更换 Tox ID（nospam）会让旧 ID 失效；toxee 目前还没有在附近页
  提供这一入口。
- **仅前台。** 后台不运行任何东西，所以只有 App 打开时你才可被发现。
